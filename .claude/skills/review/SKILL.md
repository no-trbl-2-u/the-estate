# review — `a → Appraisal`

Judge the artifact against what it was trying to be, not against what you
would have made. Be as precise about what it does well as about what it does
poorly. Produce an `Appraisal`.

## Agent binding (hard)

Performed by **The Assayer** (`assayer`) and by no one else. If that agent is
unavailable the verb does not run; the Steward reports the gap.
