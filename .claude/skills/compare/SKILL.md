# compare — `[a] → Appraisal`

State the criteria **before** judging — criteria invented afterward are a
rationalization. For each option name what it is best at and the conditions
under which it wins. A comparison with a foregone conclusion has compared
nothing.

## Agent binding (hard)

Performed by **The Assayer** (`assayer`) and by no one else. If that agent is
unavailable the verb does not run; the Steward reports the gap.
