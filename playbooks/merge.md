# Playbook: merge (absorb)

**Composition:** `frame ▸ retire` — no new verb required.

When the convergent pass surfaces its highest-value notice — *two records are
secretly one idea* — this is how they become one, using only machinery that
already exists:

1. **Pick the survivor.** Usually the record with more forward motion; the
   operator decides.
2. **`frame` (or `distill`) on the survivor**, with the handoff packet
   carrying the relevant artifacts from **both** records. The new artifact's
   `inputs:` cites paths in both — and that cross-record `inputs:` chain *is*
   the merge edge, derived exactly as ADR 0005 promises. Nothing is
   hand-drawn.
3. **`retire` the absorbed record** with the reason `absorbed into idea-NNNN`.
   It is preserved whole, like everything else; its artifacts remain the
   cited sources of the survivor's.
4. The Steward closes both records per protocol.

The `relates` edge the notice proposed may already exist; leave it — it
records that the connection was *seen* before it was acted on.
