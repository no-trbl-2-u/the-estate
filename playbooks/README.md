# Playbooks

A playbook is a **composition of verbs** — nothing more. It is never the
required route: the Steward derives routes from the gap between an idea's
current artifacts and Seed-shape, so two ideas rarely travel the same path.
Playbooks exist as worked examples and as shorthand for compositions the
operator finds themselves repeating.
