## Decisions

- **The residue is filed here, not deferred.** `system/TYPES.md` files a
  residue on the record the *observations* belong to, normally idea 0001.
  There was no such record; creating one was the minimum act that let the
  observations be typed rather than lost to the session.
- **The number 0001 is reclaimed for the estate's own record**, matching the
  archived estate's convention (ADR 0020 called it "the correct home for a
  convention that governs every record"). T's first idea record will be
  `idea-0002`. Renumbering is a `git mv` if T prefers otherwise — references
  here are id-based (ADR 0033).
- **The crash found in item 1 was fixed in the same session** rather than only
  reported, because it made the empty estate unusable for the operator about
  to start using it. The residue records it regardless: a fixed defect that
  went undetected is still evidence about the machinery. The same applies to
  the office misattribution (item 7).
- **Item 7 was added to the residue before the close, not superseded after
  it.** Artifacts are immutable *once written* (`system/TYPES.md`), and the
  seal is the close — which this state is. Nothing had been committed when the
  eighth observation arrived, and a residue that omitted the best evidence for
  its own central claim would have been a worse artifact, honestly produced.
  Recorded here so no reader has to reconstruct it from a diff.
