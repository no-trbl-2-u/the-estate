# State 0011

## Established

**The estate's first prior-art and viability Findings are filed.** The operator
asked, verbatim: is the idea of this project dumb, already implemented, and is
anything obvious missing? The Factor searched five territories — AI
idea-development pipelines, agentic PKM, multi-agent Claude Code patterns,
git-as-database lifecycle systems, and the estate's specific differentiators —
across 32 sources, one day, English-language, one index, fetch-only.

What came back, load-bearing:

- **The composition is unfound.** No located system combines domain-general
  idea records + hard-bound persona verbs + immutable snapshot state + a
  terminal export contract. Not even two of the three pillars together.
- **Nearly every part is implemented, some at massive adoption.** BMAD (~52k
  stars) is the closest single neighbor — named personas elaborating a raw
  idea through typed markdown artifacts. GitHub Spec Kit (~93k stars) is
  staged idea→plan with repo-persistent artifacts. Both are idea→software
  delivery pipelines, not idea gardens.
- **Digital gardens are the nearest philosophical prior art** (maturity
  states, epistemic-status labels, classification without gating) — but
  notes, not records; no verbs, no agents, no export.
- **The state substrate is convergent with published research** (ESAA,
  PROJECTMEM: event-sourced, append-only, git-versioned agent state). The
  copy-forward snapshot discipline specifically was not found.
- **The persona-roster-plus-dispatch pattern is the dominant ecosystem
  pattern.** The estate's novelty there is only making the binding *law* with
  a gap-reporting failure mode — and peers enforce their bindings in
  code/YAML where the estate relies on compliance.
- **Enterprise idea management does ideas-as-lifecycle-objects — and gates
  every stage.** Grade-never-gate as an explicit inversion of phase-gate was
  found nowhere. Same for Seed-style export contracts, falsifiability
  classifiers on visions, and reachability ranking. Real but thin: governance
  and contract design, not capability.
