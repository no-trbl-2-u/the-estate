# State 0017

## Established

`capture` was dispatched to The Gardener to file the residue of state 0016's
structural session, producing
[`0009-load-bearing-updates-residue.md`](../artifacts/0009-load-bearing-updates-residue.md)
— nine items, `type: SessionResidue`. **The first exercise of anything added in
this round**, and the type's first instance under ADR 0026.

It was also the first real test of the rule `AGENTS.md` states and state 0016
did not follow: the verb was dispatched rather than performed inline, in a
session where performing it inline would have been trivially easy.

### The residue found a live defect the Steward's own sweep had missed

Item 3. State 0016 claimed the estate "agrees with itself everywhere, verified
by grep rather than asserted." The grep was real; **its perimeter was one ring
too small.** It covered `system/`, `.claude/`, `reference/`, `README.md`,
`AGENTS.md`, `VISION.md`, `docs/GLOSSARY.md`, and `templates/` — and the
falsified claim that `relates` is *"the only hand-authored edge"* was still
standing in four files, two of them load-bearing:

- **`AGENTS.md`** — injected into every Claude Code session at startup
- **`templates/idea.md`** — copied into every new record at birth
- `AUDIT-PROMPT.md` — the standing brief handed to outside auditors
- `docs/architecture.html` — the published visual

All four are now fixed. `docs/adr/0005` and the ADR index row that carry the
same claim are **immutable and correctly left alone** — they were true when
written, and ADR 0024 records the supersession.

### The residue corrected the Steward

The handoff packet asserted as raw observation that **`decide` has never run**.
It is false, and has been since 2026-08-28:
[`0008-human-attention-tag.md`](../artifacts/0008-human-attention-tag.md) is
`type: Decision`, `produced-by: decide` — The Chancellor's first sitting, and
the subject of state 0015. The Gardener checked it, dropped the item, and said
so.

The claim was true when residue `0007` made it, was falsified two days later,
and was carried forward by the Steward into a packet as though still current.
That is the mechanism the correction is really about, not the fact.

## Decisions

**The dispatch stood.** `capture` producing `SessionResidue` was performed by
The Gardener with a handoff packet, per `system/LAW.md`. The residue's value is
partly *because* of that: a Steward writing its own residue would have been
reporting on itself, and item 3 is precisely the kind of finding a self-report
does not produce.

**The four fixes were made by the Steward inline, not dispatched.** They are
documentation corrections to files the writer seam does not assign to any
agent — the same category as the rest of the round. Item 2 of the residue is
about exactly this category, and it remains open below rather than being
settled here.

## Tensions

**Rigour versus aim.** The Gardener's framing, and it is the sharpest thing in
the artifact: the session's checking was genuinely careful and *pointed one ring
inside the actual blast radius every time*. That is not sloppiness, and it
cannot be fixed by trying harder — only by defining the perimeter.

**Self-report versus record.** The residue practice is the estate's only
self-observation mechanism, and it has now been shown to propagate a stale
belief unless independently checked. This argues `challenge` on a residue should
be routine rather than optional — residue `0001` was materially improved by it,
and `0009` is written `challenged: false`.

**Item 2 is deliberately soft, and The Gardener said so.** It names the
structural-session exemption as "a gap somebody should decide," leaving both
readings — deliberate exemption, or violation of a rule made the same day —
standing. That call is T's.

## Open questions

3. **What owns the `system/` → `ui/` generation dependency?** No verb, no check,

   `ui/` and idea-0004's records knows it exists.
4. **Should the sweep perimeter be defined anywhere?** The working definition
   was `system/` + `reference/` + `GLOSSARY.md`, and it is demonstrably one ring
   too small.

Carried forward from state 0016, still open: **Phase 6's live verification** —
audience, jot, and graft on real ground, plus payload when a record is ready.

the four new mechanisms.
