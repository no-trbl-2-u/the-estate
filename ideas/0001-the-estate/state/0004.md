# State 0004

## Established

T proposed renaming or duplicating `AGENTS.md` as `CLAUDE.md` "to make sure
that Claude Code 100% reads it." Both were declined in favour of the harness's
own mechanism: `CLAUDE.md` is now a single `@AGENTS.md` **import**, expanded
into context at session start, plus a short Claude-Code-specific note. Sealed
as **ADR 0019**.

The defect was real and observed in this very session: `CLAUDE.md` was injected
at startup and `AGENTS.md` was not, so the standing identity arrived only
because the main session elected to spend a tool call on ADR 0015's prose
pointer. That closed F-3 by compliance; the import closes it by loading.

A sweep confirmed the orientation has exactly one home. The repository contains
one `AGENTS.md` (root) and one `CLAUDE.md` (root) — no nested orientation files
in any subdirectory, and no rules files for other harnesses (`.cursorrules`,
`.github/copilot-instructions.md`, `.windsurfrules` are all absent, as is
`.github/` itself). `.claude/agents/` holds the twelve agent definitions, which
are a different population entirely.

## Decisions

- **Import, not duplicate.** Two copies of the orientation is the drift failure
  the estate is built against; nothing would keep them equal.
- **Import, not rename.** `AGENTS.md` is named in `system/LAW.md`, all twelve
  agent definitions, `README.md`, `AUDIT-PROMPT.md`, and ADRs 0013–0015, which
  are immutable record. A rename falsifies them or breaks them, and binds the
  orientation to one harness against self-containment.
- **The fix is main-session-scoped, and that is correct.** Memory files reach
  neither `AGENTS.md`'s nor `CLAUDE.md`'s content to a spawned agent; agents are
  served by reading `system/LAW.md` directly. F-3 was always a main-session
  defect. A rename would not have helped the agents either.

## Gold nuggets

- A pointer that says "go read this" closes a reachability gap by compliance;
  an import closes it by loading. The first reply is where that difference
  lands.
- The orientation is now loaded in full every session, which makes its length a
  live cost: 134 lines against a 200-line adherence guidance. Growth belongs in
  `system/` or a skill, not in `AGENTS.md`.
