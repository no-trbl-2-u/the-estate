## The six items

### 1. The estate's first fully remote arc — and merge became ratification.

Research and explore ran in a cloud session with no local operator present;
the work traveled to T as a pull request, and T's authority was exercised by
*merging*. The PR became a de facto ratification gate that no law names.
`main` only moved when T said so — which honors "T decides" — but through a
mechanism (branch + PR + merge) the estate's own documents never mention.

### 2. Fast-track, third sighting: confirmation degrades under absence.

The operator described intent in their own words ("determine ways to focus
the estate"); the Steward mapped it to `explore`, named the runner-up
(`review`) only in passing, and acted without the confirmation exchange the
Steward spec describes — because the operator was not present to answer. The
confirmation step degrades under remote/asynchronous operation by necessity,
not choice. Fast-track remains unnamed in law.

### 3. The cost of watching.

Roughly twenty-four hourly check-ins on a quiet PR produced zero
information — every poll found the same clean, unreviewed head. Gap 3's
candidate add (proactive resurfacing / heartbeat behavior) now has an
observed cost profile from inside the estate's own walls: proactive
machinery is not free, and most of its ticks are silence.

### 4. Agents self-limiting, honestly.

The Factor stayed fetch-only and bounded every absence claim; the Forager
flagged his own `challenge` hint as conflicted ("written by an agent
proposing to shrink his own household"). Voluntary, unrecorded good
behavior — the same shadow-law species day two named, now observed in
dispatched agents rather than the main session.

### 5. Decisions happen; the Chancellor doesn't.

`decide` has been hinted four times and never run — and meanwhile a real
decision (merge the PR, ratify two artifacts and three states into `main`)
was made by T through git, outside any verb. The estate's decisions are real
but increasingly happen *beside* the machinery built to seal them.

### 6. The type system stretched but held.

`explore`'s a→a rule forced the focus menu to be `type: Findings` because
its input was Findings — a document that is really a menu of options wore a
survey's type. Composition stayed sound; the label creaked.

## The Gardener's read

This is mine, not the session's; keep it apart from the items above. The
first residue was about seams inside the walls; the second about habits
holding where structure doesn't; this one is about what happens when the
operator steps outside the walls entirely. Distance is the common soil of
items 1, 2, and 3: absence turned a git mechanism into a ratification gate,
turned a confirmation step into an assumption, and turned vigilance into
twenty-four silent polls. Items 4 and 5 rhyme darkly — the household behaves
honestly without being told, while the one office built to make honesty
formal (the Chancellor) has never once been summoned, and the real decisions
route around his empty chair. If there is one sentence to attack first, it
is item 5's "increasingly": two sightings of decisions-beside-machinery is a
pattern claimed, not a pattern proven.
