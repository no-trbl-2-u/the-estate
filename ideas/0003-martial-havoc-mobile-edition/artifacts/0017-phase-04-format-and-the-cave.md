# Phase 4 — The adventure format and The 5 Treasures

**Outcome.** An adventure is a file, and the first one is the cave.

**Depends on.** Phase 2.

**Steps.**
1. The format, versioned: areas (description, event table, encounter
   table, hint gated until earned), foes with special skills as Attack
   Strength bonuses and loot tables, treasures with effects, locks and
   keys, per-adventure flags, act markers, an ending screen. Documented
   in the repository so a text editor can write one.
2. The cave from Findings §4: the Flat-top mountain, Cave entrance,
   Attendants room, Dining Hall, Storage, Women quarter, Kitchen,
   Chieftain quarter; the Private Quarters behind one key held by the
   Ghost and the Beast; the Junior King as one entity across tables; the
   treasures with `I-44`, `I-38`, `I-45`, `I-41` readings; the gourd
   toggling day and night; the Monk's Dishonor; the Devil servant's 6 as
   a Hint.
3. Room adjacency from the Findings' inferred map as a room list;
   an original SVG diagram, positions decorative.
4. Tests: the file validates; every area's tables roll; the ending
   screen is reachable from a scripted run.

**Done looks like.** The format's document and the cave's file both in
the content package; a scripted Master reaches the ending screen on
fixed dice.

**Cost.** Two weeks.
