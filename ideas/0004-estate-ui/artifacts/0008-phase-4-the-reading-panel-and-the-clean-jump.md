# Phase 4 — The reading panel and the clean jump

I am The Surveyor. The tail of the build, and deliberately the tail: nothing
in it changes what the map knows, only how comfortably T reads and moves.

## What this Phase delivers

1. **The reading panel.** Click a node, the right panel opens, the map stays
   put. Header: type chip, produced-by chip with the bound agent resolved
   through `system/registry.md` (*challenge — The Advocate*), date, lenses,
   classifiers plain (`challenged: true` on 0009), `inputs:` as working links,
   `potential-next-steps` as **labels, never buttons** — the refusal rendered,
   not just recorded. Summary as standfirst; body as formatted markdown in the
   author's own voice. For `Findings`: the OKF furniture — `sources:` table
   with credibility signals, `stale_after:` compared against today, expired
   facts flagged. Markdown rendering is hand-rolled for the subset in use or
   vendored under `docs/estate-view/vendor/` — never fetched.
2. **The version breadcrumb.** *Framing — v2 (tip) ← v1 (superseded)*; landing
   on a superseded version shows the banner naming the tip, teaching the same
   reflex handoffs use.
3. **The clean jump**, as three testable properties: a place-preserving
   back-stack (return to the Starvu record finds the same scroll, same open
   panel, same selected node); head-oriented arrival (a record opens at its
   state-head, tips bright); traversable drawn edges (the `relates` layer's
   links work the day The Cartographer fills it — the affordance built now,
   the edges awaited).
4. **Search.** Titles and summaries (full-text over bodies deferred until the
   island's weight is measured, per the Horizon's cheap-unlock tier), with T's
   own words as synonyms: "sub-idea" returns version branches and
   `relates`-neighbor records, each captioned with what it actually is.

**Done looks like:** the Scene 4 acceptance test passes literally — deep in
Starvu at the fan-out with a panel open, jump to idea-0001, arrive at its
head, jump back, find everything exactly as left.

## Trigger, dependencies, cost

- **Trigger:** Phase 3's map rendering the fixture correctly (ugly-correct is
  sufficient — this Phase does not wait on weekend-two polish).
- **Waits on:** nothing else.
- **Cost:** one weekend.

## The truncation point, said plainly

If T's appetite answer cuts the route, it cuts **here**. Shelf plus map is a
working viewer; the panel saves one file-open per artifact read and the jump
saves re-orientation — comforts, not spine. The Phase exists because the
Horizon's day-one tier names it, and it sits last because the route must
degrade from the tail.

## Where a Framing assumption bites

**Assumption 5 — the glossary holds as the vocabulary contract** — bites in
every chip, caption, and synonym. The checkpoint inside this Phase: walk every
rendered label and confirm it maps through `docs/GLOSSARY.md`, with T's words
appearing only as search synonyms. If building the panel generates pressure to
push a UI term *back* into the canon, that is the named sign the UI is
redesigning the estate rather than viewing it — the term stays out, and the
pressure is reported to T.

## What this Phase refuses

Buttons on `potential-next-steps` or anywhere else that would dispatch;
editing affordances of any kind; full-text body search before the payload is
measured; and any panel feature that requires data the frontmatter does not
carry.
