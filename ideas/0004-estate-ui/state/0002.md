### The deferred decision, taken: build-time-generated

Decisive reason: **runtime parsing over `file://` does not exist** — browsers
block sibling-file fetch, so "runtime" secretly means a local server, the
moving part the Framing already leaned against. Generation also puts the viewer
in a category the estate owns (derived data, like `SURVEY.md`), keeps the graph
derivation in one testable place with idea-0003 as fixture, and keeps the file
literally *"a view, not a database."* Cost named and mitigated: **staleness** —
the open command regenerates first, and the file always displays its
generated-at time and `covers:` stamp.
