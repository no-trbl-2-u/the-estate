# Phase 4 — Operations table

The Surveyor. The Trajectory's fourth leg, the longest, and priced as
transcription because Findings §4.3 already holds the operations for
every entry in the grammar of §4.2.

**Outcome.** Every entry of the book as data the engine executes, with
a test that proves it.

**Waits on.** Phase 3 (the operations exist as functions); Phase 1 (the
table's shape).

**When.** October to November.

## Steps

4.1 **Batches.** Eight slices of ten Prompts (1–10 … 71–80), each a loop
tick: encode the entries, run `entry-check`, fix the coverage report,
commit. Prompts 72–80 are one slice with the nine ending entries.

4.2 **Per entry.** From §4.3: the five-word lead, the operations in the
grammar, `ends`. No prose from the book in this file; the lead is the
Findings' own. Each `||` branch is the entry's "Alternatively"; each
`[if none]` is R26's condition; each `[may]` is optional.

4.3 **Named traits.** The thirteen named Tags and nine named Resources
of §4.4 as quoted names with their creating and losing entries, so the
engine can find "Wanted" at 33C and "Poison of Love" at 35B and 75.

4.4 **Player-judged selectors as choices.** Every selector the engine
cannot evaluate (§4.6, last item: positive or negative Tag, love- or
parenthood-related, opposites, beloved, friendly, enemy, rival,
offensive, healing, on your person, in the city, strongest) typed with
the kind of choice and the entry's own words as the question the UI
asks. The engine pre-selects nothing for these.

4.5 **The generated test per entry.** `entry-check` scaffolds it: apply
the entry's proposals to a fixture sheet arranged so every branch is
reachable, assert the resulting sheet and ledger. The agent completes
the assertion; the scaffold names the operations so a missing one is
visible.

4.6 **Coverage.** `entry-check`'s report: for each entry, the imperative
sentences of the book's text (split at full stops, verbs from §4.2)
against the operations encoded. A sentence with no operation fails the
gate unless it carries `narrative: true` with the rule it falls under
(R07, R10, R17, R21 and the like).

## Done when

222 entry tests pass; the coverage report is empty; every undefined
operation in Phase 3 is used by at least one entry; the fixture's
operations from Phase 1 are replaced by the real table.

## Cost

Eight loop ticks, transcription-priced. Half a tick more if `entry-check`
needs its report widened.

## Left open inside this Phase

  the book's pages is worth one estate session before Phase 9. The
  Surveyor recommends it; it is not a step because the loop cannot
  perform it.
