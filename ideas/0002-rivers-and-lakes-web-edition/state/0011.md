# State 0011

## Established

The Trajectory is decomposed into twelve Phases, one artifact each in
the `phases` shape: a Phase 0 garden ahead of the route, then one Phase
per leg. Each names its outcome, what it waits on, its steps with the
human-attention tag decided step by step, its done-condition, its cost,
and what it leaves open. The fifth leg is decomposed against RPG
Windows, so its layout tag is discharged. The record is now
`build-plan`-shaped: Horizon, Trajectory and `[Phase]` exist; the Seed
owes only the payload and the provenance stamp.

Human-attention steps across the route, by hands not sign-off: the
repository under T's account, the secret values, the hosting account
(Phase 0); supplying the private text and confirming the URL is shared
with no one (Phase 8); playing the game and the falsifier dry run
(Phase 9); sending the ask (Phase 10); listing (Phase 11). Ten steps in
five Phases; the other seven Phases carry none.

## Decisions

- **Target is nexus; Phase 0 is emitted.** T's word. The garden absorbs
  the stack, the repository, the pipeline and the unlisted deploy from
  the Trajectory's second leg; Phase 2 keeps the discipline lints, the
  module layout and the empty game screen.
- **Shape is `phases`; one Phase per leg.** T's word.
- **The stack is agent-decidable.** T released it; Phase 0's stack row
  is an untagged `decide` with the record's criteria, to be sealed
  before `seed` or carried into the payload untagged.
- **Two Seed-specific skills are named**: `text-guard` (no author text
  in the public tree; the build fails without the private input) and
  `entry-check` (a per-entry test scaffold with a sentence-coverage
  report). The Sower writes them.
- **Three open questions are taken as readings, not decisions**: going
  back a beat is re-answer by replay (Phase 3 and 5.13); Quick Game
  collapses the questions into the Story beat (5.10); 21A and 46B are
  entries in the readings register (3.7). Each is labelled in the site
  and reversible by `decide`.
- **The oracle transcription is untagged agent work** over T's private
  file, as the Prompt conversion was; typos are preserved and the
  Mandarin half ships labelled unproof-read.
