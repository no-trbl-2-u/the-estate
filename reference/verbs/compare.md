# compare

| | |
|---|---|
| Signature | `[a] → Appraisal` |
| Family | aggregator |
| Performed by | [The Assayer](../offices/assayer.md) — a [hard binding](../law.md) |

Evaluate two or more options against criteria stated **before** judging —
criteria invented afterward are a rationalization. For each option, name
what it is best at and the conditions under which it wins. A comparison
with a foregone conclusion has compared nothing.

Produces an [Appraisal](../types/appraisal.md). The only verb in the
aggregator family (`[a] → b`).
