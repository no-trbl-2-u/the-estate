# envision

| | |
|---|---|
| Signature | `Framing → Horizon` |
| Family | transformer |
| Performed by | [The Architect](../offices/architect.md) — a [hard binding](../law.md) |

Write what the idea looks like **six months from now, working** — concrete,
elaborated, told from inside the working thing. Neither a wish nor a spec.

A [Horizon](../types/horizon.md) should attempt its own falsifier ("what
would make this wrong"). If none can be stated it is classified
`horizon: unfalsified` — an honest label, never a block; a later
[challenge](./challenge.md) pass can upgrade it.

Route hints: usually `[challenge, chart]`.
