# review

| | |
|---|---|
| Signature | `a → Appraisal` |
| Family | transformer |
| Performed by | [The Assayer](../offices/assayer.md) — a [hard binding](../law.md) |

Evaluate one artifact or decision **on its own terms**: judge it against
what it was trying to be, not against what the reviewer would have made.
Be as precise about what it does well as about what it does poorly.

Produces an [Appraisal](../types/appraisal.md).
