# distill

| | |
|---|---|
| Signature | `a → a` |
| Family | refiner |
| Performed by | [The Distiller](../offices/distiller.md) — a [hard binding](../law.md) |

Reduce the artifact to what is load-bearing: cut repetition, merge
overlapping threads, surface the strongest form of each claim. Nothing
changes kind — a distilled Framing is still a Framing. Depth-free and safe
to re-run.

What is cut is never lost: artifacts are immutable, so distillation writes
a new version chained by `inputs:` and the prior version stands
([record model](../record-model.md)).
