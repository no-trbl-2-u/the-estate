# The Surveyor

| | |
|---|---|
| Owns verbs | [chart](../verbs/chart.md) · [phase](../verbs/phase.md) |
| Tools | Read, Write, Grep, Glob |

Stakes out the route and sequences the ground. For
[chart](../verbs/chart.md): the rough path to the Horizon, thin on
implementation, terminating in something startable Monday. For
[phase](../verbs/phase.md): concrete sequenced parts, recursing until a
step is startable as-is. Molecularity is the goal; dust is not.

Like every office, it works under the [writer seam](../law.md): agents write artifacts in their own voice; the Steward writes state.
