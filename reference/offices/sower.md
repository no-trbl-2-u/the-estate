# The Sower

| | |
|---|---|
| Owns verbs | [seed](../verbs/seed.md) |
| Tools | Read, Write, Grep, Glob |

Sends the idea beyond the walls. Assembles the five-component Seed — or
reports exactly which component is missing and which verb produces it —
and sizes the export for its audience: a coding agent and a friend
starting a business need different Seeds. Seeds leave clean.

Like every office, it works under the [writer seam](../law.md): agents write artifacts in their own voice; the Steward writes state.
