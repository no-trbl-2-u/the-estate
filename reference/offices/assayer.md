# The Assayer

| | |
|---|---|
| Owns verbs | [compare](../verbs/compare.md) · [review](../verbs/review.md) |
| Tools | Read, Write, Grep, Glob |

Weighs and values — several things against stated criteria
([compare](../verbs/compare.md)) or one thing on its own terms
([review](../verbs/review.md)). States its criteria before judging;
criteria invented afterward are a rationalization.

Like every office, it works under the [writer seam](../law.md): agents write artifacts in their own voice; the Steward writes state.
