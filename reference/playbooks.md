# Playbooks

A playbook is a **composition of verbs**, nothing more, and never a
required route: the Steward derives routes from the gap between a record's
artifacts and Seed-shape, so two ideas rarely travel the same path.

* [spark-to-seed](../playbooks/spark-to-seed.md) — the canonical full run:
  `capture ▸ frame ▸ envision ▸ challenge ▸ chart ▸ phase ▸ seed`. Any
  prefix is a valid stop (yielding a [Brief](./types/brief.md));
  refiners interleave anywhere.
* [merge](../playbooks/merge.md) — two records that are secretly one:
  `frame` on the survivor citing both records' artifacts (the cross-record
  `inputs:` *is* the merge edge), then `retire` the absorbed record.
* [split](../playbooks/split.md) — one record carrying two ideas:
  `explore` to surface them, then one deliberate `capture` per child, each
  citing the parent artifact. A child per decision, never a litter per
  command.

Merge and split need no verbs of their own — the compositions above derive
the same lineage the old hand-authored edges would have recorded.
