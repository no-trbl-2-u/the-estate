03 · functional core

Verbs are functions

Molecular, single-purpose, composable. A playbook is nothing but f ∘ g.

Composition only works when the output type of one verb is the input type of the next. That contract is what makes the Steward able to derive routes: it knows what a record has, it knows Seed-shape, and it computes the difference. Routes differ because gaps differ — which is how you get a different path every time without ever hand-authoring a pipeline.

04 · immutable state

Nothing is ever edited

Every session copies the last snapshot forward and writes a new one.

This single rule buys four features that would otherwise each need building. Time travel is opening an older file. Branching is copying forward from an older snapshot — and the original is untouched, because nothing is ever touched. Reviving a retired idea is just branching. And old states become documentation: each one carries the decisions made, the tensions still live, and the gold nuggets worth keeping verbatim.

05 · lineage

Edges are derived, not drawn

The graph is a view, not a database.

Every artifact records what it consumed (inputs:) and what it produced. So parent, branch, merge and split are read backwards off the composition chain — nobody maintains them. They're the trace of the function calls.

One edge is hand-authored: relates. No verb produces it. It comes out of a head — “this idea reminds me of that one” — and it is the single most valuable output in the system, because it is the connection the machinery cannot make.

The trade: a derived edge exists only if the agent faithfully wrote inputs:. Miss it once and that lineage is gone with no reconstruction path.

06 · types

What a Seed must contain

The terminal type. Five components, or it is a Brief instead.

  1. Horizon — the elaborated six-month vision.
  2. Trajectory — the rough path toward it.
  3. Next concrete move — a specific thing the recipient can do. For a project, start Monday; for a conjecture, the case to test first; for a story, the scene to write first.
  4. At least one refusal — a named thing this will not become. A project refuses scope; an inquiry refuses a line of attack; a story refuses a genre.
  5. Provenance stamp — one line, origin: idea-0142 @ state/0007. The only thing that travels backward.

Classification, not certification

Types check presence, never quality — so quality is recorded structurally and nothing is ever blocked. An unfalsified Seed exports freely; it just says so on the tin.

09 · the portfolio

Which idea deserves your Saturday

survey computes the sitemap. Ranked by reachability × appetite — never by closest-to-done.

Ranking by proximity to finished would sort a creative life by tidiness and bury every raw idea forever. So the score asks a different question: how much would one verb move this? — which favours early, high-leverage records. Appetite is the hand-set input no metric can compute. Drift is displayed but never scored, because drift usually means the idea is working.

10 · the law

Three rules, one seam

  1. Agents are a specific person. Named, self-aware, thematic to the estate.
  2. Verbs are verbs. Never personas.
  3. Specific agents perform specific verbs — a hard dependency. No fallback, no substitution. If a verb's agent is unavailable, the verb does not run and the Steward reports the gap.
Agents write artifacts. The Steward writes state.

State is immutable copy-forward, so its sequence needs a single allocator — and the close protocol needs the whole-session view only the Steward has. Meanwhile the agent's own words land in the record unmediated, because a summarizing relay is where thinking goes to die.

The binding is law obeyed, not law compiled.

Nothing in the harness enforces any of this. A skill is an instruction sheet loaded into the main session; it names its bound agent and the Steward chooses to comply. That is precisely why the Steward's identity is standing rather than optional — there is no window in which a plain assistant handles a request before the estate wakes up.

Falsifier, verbatim: “I'll have failed if within a month, I have no evidence of using this outside this repo.” Check date 2026-09-25. The named failure mode is that building think-tank is more interesting than using it.

The law lives at system/LAW.md and every agent reads it directly. This page states the shape; system/ states the rules.
