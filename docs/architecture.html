An idea foundry. Ideas enter loose, pass through thirteen offices as typed values, and leave as Seeds — a horizon plus a trajectory, ready to be built somewhere else.

01 · the mechanism

How a request becomes work

Nothing here is automatic. Every arrow is a decision something makes.

The main session is The Steward by standing identity (CLAUDE.md → AGENTS.md). It reads the registry, derives the route, and dispatches the verb to its bound agent — it never performs one. For a new idea it creates only the record shell, then dispatches capture: The Gardener writes the first Spark, because recording the origin is not capturing it.

The skill file for a verb is an instruction sheet, not a trigger: it loads into the Steward's context and names its bound agent. The binding is law obeyed, not law compiled — which is exactly why the Steward's identity is standing rather than optional.

03 · the types

Ten typed values, seven verb families

Type is for the machine — composition and gap-derivation. Shape is for the reader.

Composition works because the output type of one verb is the input type of the next. That contract is what lets the Steward derive routes: it knows what a record has, it knows Seed-shape, and it computes the difference. Routes differ because gaps differ.

Classification, not certification. Types check presence, never quality. Quality is recorded structurally — horizon: falsifiable|unfalsified, challenged: true|false, trajectory: actionable|abstract — and the label travels with the export. Nothing is ever blocked. Grade, never gate: you cannot write a falsifier for a wish.

Artifacts are immutable. A refiner writes a new file whose inputs: names its predecessor; the current version is the tip of that chain. Findings, Appraisal, and Decision are not Seed components — the route reaches their verbs through tensions and open questions, not Seed-distance.

04 · state over time

Nothing is ever edited

Every session copies the last snapshot forward and writes a new one. That single rule buys four features.

One rule, four features, no machinery:

You wantYou do
Time travelOpen an older file. It never changed.
BranchingCopy an old snapshot forward into a new record; its previous: names the exact origin (ideas/README.md has the four steps).
RevivalBranching, from any snapshot of a retired record.
LineageRead it off the inputs:/previous: chains. The graph is a view, not a database.

The trade is real: a derived edge exists only if the writer faithfully recorded inputs: — miss it once and that lineage is gone. One edge is exempt because no machinery can make it: relates, out of a head, the most valuable edge in the system. The Cartographer names it and the why; the Steward writes it, because record frontmatter is state and state has one writer.

07 · the portfolio

Which idea deserves your Saturday

survey computes the sitemap. Ranked by reachability × appetite — never by closest-to-done.

Ranking by proximity-to-finished would sort a creative life by tidiness and bury every raw idea forever. So reachability asks instead: of the typed steps still between this record and Seed-shape, what fraction does the best next verb complete? A raw Spark five steps out scores 1/5 — never zero. Appetite is the hand-set heat no metric can compute (default 1; 0 means deliberately cold). Drift is displayed but never scored, because drift usually means the idea is working.

Surfaced above the ranking, because it is the highest-value output: the convergent notices — two records that are secretly one idea, a record one verb from a Seed sitting idle, a dead Spark that fits a live record. A record whose relates degree grows while its own state stays flat earns connective — a hub doing work that isn't Seed-work — and leaves the ranking entirely. The trigger is inbound use without forward motion, never dormancy alone.

08 · the law

Three rules, one seam

  1. Agents are a specific person. Named, self-aware, thematic to the estate.
  2. Verbs are verbs. Never personas.
  3. Specific agents perform specific verbs — a hard dependency. No fallback, no substitution. If a verb's agent is unavailable, the verb does not run and the Steward reports the gap.

Agents write artifacts. The Steward writes state — and record frontmatter is state. The agent's words land in the record unmediated, because a summarizing relay is where thinking goes to die; the state sequence gets a single allocator, because immutable copy-forward needs one. And dialogue crosses the seam through the Steward: a dispatched agent that needs the operator returns the question, never assumes the conversation.

"I'll have failed if within a month, I have no evidence of using this outside this repo." — check date 2026-09-25. The named failure mode is that building The Estate is more interesting than using it.

The law lives at system/LAW.md and every agent reads it directly. This page states the shape; system/ states the rules.
